# Chat with Repo

This project provides a conversational interface to interact with a codebase.

## Project Structure

- `src/`: Contains the main application source code.
  - `config/`: Configuration files.
  - `db/`: Database connection and utilities.
  - `routes/`: API routes (health, query).
  - `scripts/`: Utility scripts (e.g., `ingest-cli.ts`).
  - `services/`: Core application logic (chunking, embeddings, generation, GitHub integration, ingestion, repository management, retrieval).
- `migrations/`: Database migration scripts.
- `test-folder/`: Test files.
- `docker-compose.yml`: Docker Compose configuration for local development.
- `package.json`: Project dependencies and scripts.
- `tsconfig.json`: TypeScript configuration.
